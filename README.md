# Business Ai — AI-помощник для бизнеса

Telegram-бот: https://t.me/BusinessAi_Official_bot

**Описание:** AI-помощник для бизнеса. Автоответы клиентам, консультации, создание и публикация постов, сбор заявок 24/7.

## Возможности

- **Автоответы клиентам 24/7** — мгновенные ответы на сообщения
- **Консультации** — умные ответы по бизнесу, услугам, ценам
- **Создание и публикация постов** — генерация контента + отправка в канал/чат
- **Сбор заявок** — удобная форма заявки с сохранением и уведомлением
- **Меню и команды** для быстрого доступа

## Быстрый старт

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env`:
```
BOT_TOKEN=8947636785:AAEHgcdIj7jsSGnipAynXbsib-ZuYn2QRTY
ADMIN_IDS=ваш_telegram_id
CHANNEL_ID=@ваш_канал_или_id   # куда публиковать посты (опционально)
```

3. Запустите:
```bash
python bot.py
```

## Важно

- Включите **Business Mode** у бота в @BotFather → Bot Settings → Business Mode → Turn on
- Для автоответов от имени аккаунта подключите бота в Telegram → Settings → Business → Chatbots

## Структура

- `bot.py` — основной файл
- `handlers/` — обработчики команд и сообщений
- `keyboards/` — клавиатуры
- `services/` — логика AI-ответов, заявок, постов
- `data/` — хранение заявок (JSON)
